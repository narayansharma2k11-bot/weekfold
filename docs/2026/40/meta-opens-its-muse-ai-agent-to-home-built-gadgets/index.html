Meta opens its Muse AI agent to home-built gadgets

New open-source code lets hobbyists run Meta's personal AI agent on cheap boards such as the ESP32 and Raspberry Pi.

Meta released open-source code on 2 October that lets developers build their own hardware for Muse, the personal AI agent it launched in September. The SDK runs on ESP32 microcontroller boards and small Linux computers, so builders can attach screens, buttons, sensors and other devices, from colour e-ink notification panels to tiny touchscreen 'charms'. Meta also announced Muse Home Link, a USB adapter free to US subscribers that lets the agent reach devices on a home network.

Meta warns builders to proceed at their own risk, and reviewers note that although the code is open, Meta controls the access tokens needed to use it and can revoke them. The move came days after OpenAI launched its rival 'dots' agents.

Why it matters

Big Tech's race to put AI agents into everyday objects is moving from phones to homes, raising questions about control and privacy.
