WEEKLY INSTAGRAM POSTS (current method): edit the N list in promo/instagram/gen.py (the 5 biggest stories of the newest edition), make sure the site runs on localhost:8765 (cd docs && python3 -m http.server 8765) if the screenshots in promo/instagram/shots need retaking, then `python3 promo/instagram/gen.py`. It renders 10 evergreen ads + 5 news posts (1080x1350) into promo/instagram/out/. Use koala poses from src/koala/*.webp (point, shock, thumb, worry, mega, globe, mug, wave, magnify, sun, hang, read, sleep, mail...). No koala on stories about deaths or violence.

Instagram story templates (1080x1920). Copy d2.html as a starting point (phone(), quiz(), facts() helpers in pastel.js, styles in pastel.css), put each story in a `<div class="story" id="sNN">`, then `python3 scripts/social/render.py <html file relative to this folder> out/` renders one PNG per .story. Koala art: src/koala/*.webp. Story photos: data/photos/ (or docs/img/).
